# Historical modular evidence

These captures precede the final native integration receipt in rsibot PR #188.
They retain their original scope and source identities; do not add test counts
across runs or attribute the original 90-row results to the later cache delivery.

Byte-exact scripts, patches, non-newline-terminated captures and large raw records
are published as `.gz` or `.xz` files. [compressed-captures.json](compressed-captures.json)
maps original receipt paths to the compressed files and gives both SHA-256 hashes.
Decompress to recover the original bytes; no formatting or semantic edits were
made to those captures. Local original files remain archived and protected.

The final Linux/native report is available in
[rsibot PR #188](https://github.com/s1korrrr/rsibot/pull/188).
